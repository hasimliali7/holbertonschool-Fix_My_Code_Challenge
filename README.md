# holbertonschool-Fix_My_Code_Challenge

This repository contains solutions for the "Fix My Code" project. The goal of this project is to dive into existing codebases, identify logical bugs, and fix them without rewriting the entire program.

## Technologies Used
* Python 3
* JavaScript (Node.js)
* Ruby
* C Programming

## Requirements
* All files are compiled and tested on Ubuntu 20.04 LTS.
* All Python scripts follow the `pycodestyle` (PEP 8) style guide.
